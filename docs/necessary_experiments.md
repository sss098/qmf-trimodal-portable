# 投稿所需的最小补充实验

以已完成的 `noise_aug_v1` 三模态 QMF 和等权融合为参照，新增以下五组。原实验结果不覆盖，网络结构、输入处理、患者划分和 QMF 公式均保持原设置。

| 参数名 | 训练内容 | 目的 |
|---|---|---|
| us | ResNet50 及分类头 | 独立超声基线 |
| emg | 六通道肌电 Transformer 及分类头 | 独立肌电基线 |
| table | 表格 MLP | 独立表格基线 |
| us_table | ResNet50 + MLP，QMF 联合训练 | 检查加入肌电是否带来增益 |
| no_noise | 原三分支 QMF，关闭额外噪声增强 | 区分噪声增强带来的作用 |

## 运行

```bash
cd /home/wp24/mix/qmf_trimodal_joint_v1_4
bash scripts/train_necessary_experiments.sh all
```

串行运行五组，无需同时启动多个任务。也可将 `all` 换为表中任一参数名，只运行该组。中断后重跑相同指令；通过 `--resume` 恢复匹配代码、配置和数据的轮次检查点，跳过已完成折。

默认 Python 为 `/home/wp24/miniconda3/envs/mix/bin/python`，可通过 `PYTHON_BIN` 环境变量覆盖。配置使用本机数据路径。

## 固定训练协议

- 复用原 85 名患者和 split_seed=20260911 的五折；每折 51 人训练、17 人验证、17 人测试。
- 种子 42、43、44，每组得到 15 个最终折模型；五组共 75 个最终折模型。
- 选轮阶段跑满 100 轮（patience=100），根据验证 log loss 选择轮数 E；重新初始化，在 68 人开发集上训练 E 轮，最后评价测试集。不是每个最终模型固定重训 100 轮。
- 优化器 AdamW，batch_size=6，weight_decay=0.001；超声骨干 lr=1e-5，其他参数 lr=2e-4；梯度裁剪范数 5，无学习率调度。
- 超声以原 ImageNet 权重初始化，肌电及表格随机初始化；无额外任务预训练。
- 单模态仅一次类别加权交叉熵。使用 `equal_late` 入口，但单分支时其输出是恒等映射，不进行多模态融合或 ranking。
- 双模态保持 QMF 的 logsumexp/10 系数、加权 logits 求和、融合 CE + 两个分支 CE + 0.1 ranking；ranking 模式为 positive_margin。
- 为保持分支初始值可比，初始化仍按原顺序执行，随后移除不参与实验的网络；未选网络不进入优化器和模型文件。
- 前四组保持原噪声抽样：每患者以 0.5 概率从原三种模态等概率选择一种加噪，因此每种保留模态受扰动概率仍为 1/6。抽到被移除的模态时不影响预测，避免把单模态的加噪概率提高到 0.5。
- `no_noise` 仅关闭该额外噪声机制，超声原有翻转、亮度和对比度增强继续保留。
- 训练仍随机取一张超声、每段 8 个肌电窗口；评价对所选模态使用全部图像/窗口。数据集加载沿用原路径，未针对单模态另写数据预处理。

## 输出与分析

结果位于 `artifacts/runs/necessary_<参数名>_v1/`。单模态方法目录为 `equal_late`，另外两组为 `qmf`。每组保存逐折模型、配置、训练历史、患者划分、逐种子 OOF 预测、三种子平均预测及指标。

主要读取 `<方法>/summary.json` 与 `<方法>/ensemble_predictions.csv`，以患者配对方式和原 `noise_aug_v1` 结果比较，并报告差值的 95% 置信区间。单模态比较使用融合最终输出对应的患者级预测，不再用联合模型的内部分类头替代独立训练结果。

无噪声组训练完成后，还需按原扰动协议评价其模型，才能比较鲁棒性；仅看干净数据上的 summary 不足以回答该问题。

本次不增加 TMC、其余两个双模态组合或更多 ranking 变体。若后续要声称每种模态均具有独立增益，再补齐模态组合。

新增实验使用独立目录。旧模型和结果仍保留；旧训练检查点包含旧代码指纹，不应使用修改后的代码尝试续训旧实验。
