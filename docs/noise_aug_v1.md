# 第一版改进：训练时加入模态质量扰动

## 改什么、为什么改

既有测试中，强超声噪声使 logits 和能量质量系数同时异常增大；肌电受损后 q 也未随损失增加而下降。当前训练没有覆盖这类输入。这一版以训练分布扩展为切入点，让模型在分类监督下学习受扰动的输入，检验异常响应能否减轻。

只新增训练阶段的单模态高斯扰动。保留 ResNet50、原六通道肌电 Transformer、表格 MLP、患者对齐、特征算法、QMF 的能量权重和正间隔排序公式。肌电仍使用现有每通道 24 项特征；噪声作用于波形后重新计算这些特征，不更换为另一套 MATLAB 特征。

每个训练患者每次被采样时，以 50% 概率保持原有处理，以 50% 概率随机选一条模态加噪。三条模态等概率选择，每次只扰动一路；强度在零与指定上限间均匀抽样。原先的超声翻转、亮度和对比度增强继续使用。

| 模态 | 噪声标准差范围 | 处理 |
| --- | --- | --- |
| 超声 | 0～0.10，[0,1] 像素单位 | 三通道共享噪声、裁剪到 [0,1]、恢复 ImageNet 归一化 |
| 肌电 | 0～1.0，训练集标准化单位 | 在连续片段上产生噪声，按原采样位置取窗口，共享重叠样本噪声，重算 144 维特征 |
| 表格 | 0～1.0，训练集标准化单位 | 对原训练集填补和标准化后的指标加噪 |

验证和常规测试保持干净输入；受扰动测试仍由独立评估入口运行。此方案不翻转标签、不调整测试阈值、不修改原实验结果。它是根据已有测试发现提出的探索性改进；新结果不能作为未接触测试集的独立确认。增强不保证 q 随损失下降，也没有直接消除能量函数的尺度敏感性。

## 对照与训练参数

同一配置训练等权融合和 QMF，两者使用相同增强与划分。历史主线目录为 `artifacts/runs/noise_aug_v1/`；独立目录的启动脚本将新训练写入 `artifacts/runs/portable_noise_aug_v1/`。与历史结果对照用于观察变化，增强等权与增强 QMF 的比较用于评估动态融合在新训练条件下的作用。本轮不单独拆分轮数设置与增强的收益。

| 参数 | 设置 |
| --- | --- |
| 种子、折数 | 42/43/44，每个种子五折 |
| 优化器 | AdamW，betas=(0.9,0.999)，eps=1e-8 |
| ResNet50 主干学习率 | 1e-5 |
| 超声分类头、肌电、表格学习率 | 2e-4 |
| 权重衰减、梯度裁剪 | 1e-3；最大范数 5 |
| 患者批量 | 6 |
| 训练肌电采样 | 每段 8 窗，共 5 段、40 窗/患者 |
| 选轮阶段 | 完整训练 100 轮，以干净验证集对数损失最低轮次选 E；patience=100，不提前停止 |
| 合并重训 | 训练集与验证集合并，从初始化重新训练 E 轮，最后评估外层测试患者 |
| 初始化 | 超声 ImageNet 权重；肌电和表格随机初始化 |
| 训练参数范围 | 三个分支全部联合训练，无冻结参数 |
| 分类损失 | 融合交叉熵 + 三路分支交叉熵，各系数 1；保留训练集类别权重 |
| QMF 排序 | positive_margin，系数 0.1 |
| 等权排序 | 无 |
| 学习率调度 | 无，保持现有训练流程 |

选轮阶段保存每轮记录和可续跑的 last.pt。最终 model.pt 是按验证选定轮数重新训练得到的模型，不是直接保存验证最优轮次的权重。旧实验 patience=12，新实验设置为100；比较时应交代此差别。

## 正式运行

```bash
cd /你的路径/qmf_trimodal_portable
bash scripts/train_noise_aug_v1.sh
```

共训练 30 个最终模型，另有对应的选轮阶段。中断后运行同一命令续跑。不要使用原正式结果目录；默认脚本已使用独立目录。

完成后执行同一套扰动评估：

```bash
bash scripts/evaluate_qmf_robustness.sh --run-name portable_noise_aug_v1
```

默认评估本次增强等权融合与增强 QMF，覆盖三个种子、五折、三种模态、五档噪声和三个噪声重复；结果保存至 `reports/qmf_robustness_portable_noise_aug_v1/`。检查干净 AUC、平衡准确率、强噪声下的性能下降、q 与损失的变化，并看配对区间。

## 快速检查

```bash
bash scripts/train_noise_aug_v1.sh --smoke
```

仅完成种子42、折0的各一轮选轮和重训，输出至 `portable_noise_aug_v1_smoke`，用于验证训练、梯度、保存和评估流程，不用于性能结论。
