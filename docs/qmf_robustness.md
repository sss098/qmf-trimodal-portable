# QMF 模态质量下降实验

这项实验复用已经训练好的最终模型，检查“模态受损 → 分支损失增加 → q 降低 → 动态融合减轻性能下降”是否在当前数据上成立。四种设置分别为等权晚期融合、当前正间隔 QMF、无排序 QMF 和原仓库排序 QMF。网络结构、融合公式、损失、原模型文件均保持现状。

## 运行

```bash
cd /你的路径/qmf_trimodal_portable
bash scripts/evaluate_qmf_robustness.sh
```

这是评估指令，不需要重新训练。默认使用 CUDA，依次读取四种设置、种子 42/43/44、五折的共 60 个最终模型。只对各模型原测试折进行推理，每个测试患者保留全部超声图像和全部肌电窗口。先核对无扰动 logits 和概率与原折外预测一致，再运行扰动；不一致时停止。归一化和表格处理直接读取最终模型中保存的训练集参数。

每次只扰动一种模态，其他两路保留该模型无扰动输出。噪声由患者编号、模态和重复编号确定，不使用方法或训练种子，因此各方法使用相同扰动。不同强度使用同一噪声方向，强度固定为 0、0.25、0.5、1、2，每档重复 3 次。

| 模态 | 扰动定义 | 最大强度的含义 |
| --- | --- | --- |
| 超声 | 在缩放、补边后的 [0,1] 灰度像素上加高斯噪声，再裁剪到 [0,1]，最后使用原 ImageNet 归一化；三通道共享噪声 | level=2 时像素噪声标准差 0.2 |
| 肌电 | 在训练集标准化后的波形上加高斯噪声；在每个连续 10 秒片段上产生噪声后按原 100 点窗、30 点步长切窗，并重新计算每通道 24 项特征 | level=2 时噪声标准差为训练通道标准差的 2 倍 |
| 表格 | 在训练集填补、标准化后的保留指标上加高斯噪声；先按原始列产生噪声，再选择当前折保留的列 | level=2 时噪声标准差为训练指标标准差的 2 倍 |

这里模拟的是模型输入的数值质量下降。不同模态的 level 不是相同物理损坏程度，不把它解释为临床采集噪声的定量模型。每种模态分别比较性能随强度的变化，不根据测试结果挑选有利噪声。

## 结果和统计

结果默认保存到 `reports/qmf_robustness/`：

- `report.md`：AUC、平衡准确率及置信区间汇总。
- `metrics_ci.csv`：全部主要指标和患者级 95% 区间。
- `paired_changes_ci.csv`：受损减无扰动的性能变化，以及 QMF 的变化减等权融合的变化。
- `quality_changes_ci.csv`：被扰动分支的 q、未加权交叉熵及其配对变化。
- `fold_quality.csv`：所有设置各折的 q–loss Pearson、Spearman、协方差、q 均值及其与 1/3 的差。等权设置中的 q 仅为从 logits 计算的诊断分数，不参与等权融合。
- `ensemble_predictions.csv`：每位患者、每个噪声重复的三种子集成预测。
- `predictions/`：逐设置、种子和折的模型输出，可用于中断续跑。
- `metadata.json`：参数、源文件校验值和分析范围。

每个噪声重复先平均同一患者的三个模型种子概率，然后计算指标，最后平均三个噪声重复的指标。不会先平均噪声预测来人为形成抗噪集成。以患者为独立单位、按类别分层配对 Bootstrap 10,000 次，各设置、强度、噪声重复共用患者抽样索引。区间针对固定模型和固定噪声实现，不包含重新训练的不确定性。

`change_minus_equal_late_change` 对 AUC、准确率等指标为正，表示 QMF 的下降较少；对 Brier、对数损失为负更好。查看这个配对差值的区间，比单看受损条件下谁的绝对分数更高更直接。各指标单独报告，不把 q 均值与 1/3 接近视为原论文总体期望条件已获证明。

## 单独补算排序诊断

下面无需 GPU 推理，只读取三个排序版本和等权模型已有的折外分数：

```bash
bash scripts/evaluate_qmf_robustness.sh --diagnostics-only
```

输出到 `reports/qmf_ranking_diagnostics/`，用于比较排序项是否改善折内质量估计。每折相关性单独计算，避免直接混合五个模型的 q 尺度。

## 快速检查与续跑

```bash
bash scripts/evaluate_qmf_robustness.sh --smoke \
  --seeds 42 --folds 0 --levels 0 0.5 --noise-repeats 1 --bootstrap 50
```

快速检查每折每类只取一名患者，结果位于单独的 `reports/qmf_robustness_smoke/`，不用于研究结论。正式实验中断后重跑原命令即可复用已完成的折；未完成的折重新推理。修改强度、重复次数或评估代码后使用新的 `--output` 目录。
